# ETL Pipeline with Python

**Problem:** Build a reliable ETL pipeline to extract, validate, transform, and load sales data into a structured database.

**Dataset:** Sample Superstore dataset, 9,994 rows.

**What I did:**

* Extracted sales data using Python
* Validated duplicates, missing values, and data types
* Transformed and cleaned the dataset
* Loaded data into MySQL dimension and fact tables
* Used logging to monitor the ETL process

**Key Results:**

* Extracted: 9,994 rows
* Transformed: 9,994 rows
* Duplicate rows: 0
* Customers loaded: 793
* Products loaded: 1,862
* Orders loaded: 9,994

* `4_etl_pipeline_py.py` — Python ETL pipeline
* `4_etl_queries.sql` — SQL validation queries
